# Zedd's Hub

The home of **Zedd's mods** for Minecraft (NeoForge): the place to report bugs, suggest ideas and read how everything works.

| Mod | Minecraft | Loader |
|---|---|---|
| **Zedd's: Cheese Making** | 1.21.1 | NeoForge |
| **Zedd's: Wooden Bucket** (bundled with the other mods) | 1.21.1 | NeoForge |

## 📖 Wiki
How to make cheese, recipes, mice, config and more: **[open the wiki](https://github.com/TenDeeZedd/zedds-hub/wiki)**.

## 🐞 Found a bug? Have an idea?
Open a new issue here: **[New issue](https://github.com/TenDeeZedd/zedds-hub/issues/new/choose)**, and pick a *Bug report* or a *Suggestion*.
You need a (free) GitHub account for that.

Before you post, please:
- search the [existing issues](https://github.com/TenDeeZedd/zedds-hub/issues?q=is%3Aissue), someone may have reported it already,
- make sure you use the latest version of the mod,
- for a crash, attach the crash report (`crash-reports` folder) or the log (`logs/latest.log`), e.g. through [mclo.gs](https://mclo.gs).
